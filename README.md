# Index Keyword Co-occurrence Network

This interactive visualization is an example of an **Index Keyword Co-occurrence Network** constructed from bibliographic data related to **Education** and **Generative AI**.

The network presents relationships among index keywords that appear together in the same documents. It can be used to explore major research themes, frequently occurring keywords, and connections among topics in this research area.

## Network Elements

- **Node:** An index keyword.
- **Node size:** The number of documents containing the keyword.
- **Edge:** A co-occurrence relationship between two keywords appearing in the same document.
- **Edge weight:** The number of documents in which the two keywords occur together.
- **Node color:** The thematic keyword cluster assigned to the node.

## Interactive Features

- Enter a document-frequency threshold to display only nodes that satisfy the selected condition.
- Use the **+** and **−** buttons or the mouse wheel to zoom the network.
- Drag the visualization to move around the network.
- Hover over a node to view its keyword, document frequency, and thematic cluster.
- Click a node to display its five most closely related keywords, ranked by co-occurrence frequency.

## Note

This visualization is provided as an illustrative example. The network structure, cluster labels, keyword frequencies, and relationships depend on the bibliographic records, keyword normalization procedure, filtering threshold, and clustering method used in the analysis.
