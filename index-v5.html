1. Author Collaboration Network

Node size represents the number of documents, edge width represents the number of co-authored documents, and color identifies a connected collaboration group. The network retains the most productive authors and their visible collaborations.

2. Source or Journal Analysis

The 20 leading publication sources can be ranked by document count or total citations.

3. Citation Impact Visualization

Each point represents one document. The vertical axis uses log₁₀(citations + 1), and horizontal jitter separates documents published in the same year. Recent documents have had less time to accumulate citations.

4. Abstract Similarity Map

Abstracts were represented with TF–IDF, reduced with truncated SVD, and projected into two dimensions with t-SNE. Nearby points have more similar language and subject content. Colors show six automatically identified clusters.
